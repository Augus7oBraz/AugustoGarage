site de Mecanica e costumizadora de motos custom com inspiração em da pagina trimph

link: 
https://github.com/Augus7oBraz/AugustoGarage.git

toda a estrutura do site baseada em cada pagina vai ser colocado desta forma, mesma em futuras atualizações.

Home (index.html)

Navbar: Menu duplo estruturado com as classes text-uppercase, fw-bold e small.

Carrossel: Resolução de quebra de layout através de container fixo (carousel-item) limitado a height: 500px.

CSS Componentes: Uso de object-fit-cover e object-position: center 25% para ajuste dinâmico da imagem.

Grid: Divisão de seções utilizando as classes row e col-md-*.

Serviços (servicos.html)

Cards: Componentes .card organizados em estrutura Flexbox com a classe align-items-stretch para garantir mesma altura.

Foco de Imagem: Uso de object-position: center top e object-position: right top para centralização dos elementos.

Tabela: Tabela de preços estruturada com .table, .table-dark, .table-hover e .table-responsive.

Orçamento e Contato (contato.html)

Formulário em Grid: Divisão de campos em colunas responsivas via sistema de grid nativo.

Inputs Bootstrap: Uso de select class="form-select" e checkboxes com form-check-inline.

Iframe: Mapa com classes de proporção do Bootstrap para redimensionamento automático.

Páginas de Estilos (caferacer.html, bobber.html, carenada.html)

Menu Dropdown: Navegação ativada através do atributo data-bs-toggle="dropdown".

Portfólio: Exibição de projetos organizados em colunas responsivas.
